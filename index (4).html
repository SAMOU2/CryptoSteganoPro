// ─── AES-256-GCM Authenticated Encryption ───
public class CipherEngine implements ICipher {

   private final SecretKey masterKey;
  private static final String ALGO = "AES/GCM/NoPadding";
   private static final int TAG_LEN = 128;

  @Override
  public byte[] encrypt( byte[] data) {
    byte[] iv = generateIV(12);
     GCMParameterSpec spec = new GCMParameterSpec(TAG_LEN, iv);
     Cipher c = Cipher.getInstance(ALGO);
    c.init( Cipher.ENCRYPT_MODE, masterKey, spec);
    return concat( iv, c.doFinal(data));
  }
}

Explique la différence entre AES-CBC et AES-GCM.
AES-CBC est séquentiel et non authentifié — vulnérable aux attaques par padding oracle. AES-GCM combine chiffrement CTR + authentification GHASH, produisant un tag de 128 bits. GCM est recommandé NIST depuis 2007 pour toute application moderne nécessitant confidentialité et intégrité.

SUPPORT

Questions Fréquentes

Quels systèmes sont supportés ?
Windows 10/11, macOS 12+ et Linux (Ubuntu, Fedora, Arch) avec Java 17+. Le JAR universel fonctionne sur toute plateforme JVM. Le .exe est un wrapper natif Windows.
Nmap doit-il être installé séparément ?
Oui, Nmap doit être dans le PATH pour les scans avancés (OS detection, NSE scripts, stealth). Les scans ARP et ping basiques fonctionnent sans Nmap via Pcap4J.
Le chatbot nécessite-t-il internet ?
Uniquement le chatbot Gemini et les fonctions OSINT en ligne. Chiffrement, stéganographie, NIDS et scan réseau local fonctionnent 100% hors-ligne.
L'application est-elle légale à utiliser ?
CryptoStegano Pro est conçu pour un usage éthique : sécurité de vos propres systèmes, formation, CTF, recherche. L'utilisation sur des systèmes tiers sans autorisation est illégale.
Puis-je personnaliser les règles NIDS ?
Oui. Le moteur accepte des règles au format Snort/Suricata. Importez, activez et désactivez chaque règle individuellement depuis l'interface graphique.
Comment contribuer au projet ?
Le projet est open-source sur GitHub. Fork, pull requests et issues sont bienvenus. Consultez CONTRIBUTING.md pour les conventions Java et l'architecture des modules.
